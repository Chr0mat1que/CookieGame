# CookieGame
CookieGame is an interactive mystery game written in Python for the Space City Hacks Hackathon.

![title](https://files.catbox.moe/clm27x.png "title")

### Implementation
TKinter was used to create the GUI and audio was implemented using PyGame. The music was made with Bosca Ceoil and sprites drwan on GIMP.

scenes.py acts as a container for all the dialogue in an easily workable format, allowing for new scenes to be added easily and without adding any more functionality. The rest of the program is implemented in main.py, which gets scene information from scenes.py.

### Dependencies
* Tkinter
* PyGame

### To start:
* Install dependencies
```
$ python main.py
```
